# Netlify 공용 영업활동 보고서

## 기능
- 기존 보고서 디자인, 계획/결과 입력, 자동 합계, 보고용 요약 생성 유지
- Netlify Blobs에 필드별 저장
- 다른 사용자의 입력을 약 3초 간격으로 가져와 화면 반영
- CSV 내보내기 및 A4 인쇄/PDF 저장 유지
- 로그인 없이 사이트 링크를 아는 사람이 접속하고 입력 가능

## 배포
1. ZIP을 압축 해제합니다.
2. Netlify 대시보드에서 기존 사이트의 Deploys 화면으로 이동합니다.
3. 이 폴더 전체를 드래그 앤 드롭 배포로 올리는 방식은 Functions와 npm 의존성을 처리하지 못할 수 있습니다. 권장 방법은 GitHub 저장소에 이 폴더의 파일을 올리고 Netlify에서 해당 저장소를 연결하는 것입니다.
4. Netlify 사이트 설정에서 Build settings가 `Publish directory: public`, Functions directory가 `netlify/functions`인지 확인합니다. `netlify.toml`에 이미 설정되어 있습니다.
5. 저장소를 연결한 뒤 새 배포를 실행합니다. Netlify는 `package.json`의 `@netlify/blobs` 의존성을 설치하고 Function을 배포합니다.
6. 배포된 사이트 링크를 팀원들에게 공유합니다. 별도 로그인은 필요하지 않습니다.

## 확인
- 사이트를 연 뒤 입력란에 테스트 문구를 입력합니다.
- 다른 브라우저 또는 시크릿 창에서 같은 링크를 열어 문구가 나타나는지 확인합니다.
- `공용 보고서 연결 완료 · 실시간 동기화` 상태가 표시되어야 합니다.

## 주의
- 공개 링크 방식이므로 링크를 가진 사람은 보고서를 열람하고 수정할 수 있습니다. 링크가 외부로 전달되면 데이터도 노출될 수 있습니다.
- 이 구성은 필드 단위로 저장하므로 서로 다른 칸을 동시에 수정해도 덮어쓰기 위험을 줄입니다. 같은 칸을 동시에 수정하면 마지막 저장 값이 남습니다.
- Netlify Blobs는 일반 DB처럼 강한 다중 사용자 트랜잭션/충돌 해결 기능을 제공하지 않습니다. 중요 자료라면 로그인, 접근제어, 백업 및 편집 이력 기능을 추가하는 것이 좋습니다.
- 무료 요금제의 사용량 및 기능 한도는 Netlify 계정 정책에 따릅니다.
